# Property Rental Management
Web-based Rental Property Management System developed with HTML, CSS, and Bootstrap for managing properties, tenants, rent payments, and rental services efficiently.
**Stratos Rental Property Management System**

A web-based Rental Property Management System developed using HTML, CSS, Bootstrap, and basic web technologies. This project helps property owners and tenants manage rental activities efficiently through an easy-to-use interface. The system includes features such as property listings, tenant management, rent payment tracking, user registration, login authentication, contact support, privacy policy, and terms & conditions pages. The project is designed to provide a simple, reliable, and user-friendly platform for managing rental properties while improving communication between property owners and tenants.

**Technologies Used:**

* HTML5
* CSS3
* Bootstrap 5

**Features:**

* Responsive Home Page
* User Login and Sign Up Pages
* Property Listings
* Rent Payment Form
* Contact Us Page
* Privacy Policy and Terms & Conditions
* Modern and User-Friendly Interface

This project was developed as part of a web development learning and mini-project initiative to demonstrate front-end development skills and, rental management concepts.
